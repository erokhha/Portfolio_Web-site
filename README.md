## About the Project

This repository contains the source code of my personal portfolio website.

The project has two goals:

- present my professional and academic background;
- demonstrate how I organize and develop a real project using Git and GitHub.

The repository itself is therefore also part of the portfolio.

## Planned Content

The first public version will include:

- About Me
- Education
- Certificates and courses
- Achievements
- Projects
- Contact information
- Responsive layout
